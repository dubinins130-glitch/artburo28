# ArtBuro28

Демонстрационный сайт студии дизайна интерьеров и ремонта «ArtBuro28» (Благовещенск), собранный на основе шаблона «Контур». Адрес, телефон, часы, перечень услуг и отзывы по смыслу взяты из публичной карточки студии в 2ГИС (24.11.2026), фотографии стоковые. KeetsCode — студия разработки.

## Запуск

Требуется Node.js 20.9 или новее.

```bash
npm ci
npm run dev
```

Откройте [локальный сайт](http://localhost:3000). Для проверки сборки выполните `npm run lint`, `npm run typecheck` и `npm run build`. Готовая сборка запускается командой `npm start`.

## Размещение на обычном хостинге

`npm run build:static` собирает папку `out/` из готовых файлов. Её содержимое нужно загрузить в корень сайта на любом статическом хостинге (например, в `public_html`). В этом режиме картинки отдаются как есть, без оптимизации сервером, поэтому все изображения заранее сжаты в WebP. Перед сборкой задайте `NEXT_PUBLIC_SITE_URL` с настоящим адресом сайта. Обычная команда `npm run build` по-прежнему готовит версию для запуска на сервере с Node.js (`npm start`).

Для GitHub Pages workflow передаёт базовый путь репозитория в `NEXT_PUBLIC_BASE_PATH`, а публичный адрес в `NEXT_PUBLIC_SITE_URL`. Локальная сборка и публикация на корневом домене используют пустой базовый путь.

## Настройка сайта

- [src/content/site.ts](src/content/site.ts) — название, регион, проекты, услуги, примерные цены, изображения и контакты.
- Для локального просмотра контактов задайте `NEXT_PUBLIC_CONTACT_PHONE`, `NEXT_PUBLIC_CONTACT_EMAIL` и `NEXT_PUBLIC_CONTACT_ADDRESS` в `.env.local`. Без этих значений прямые контакты скрыты. Режим отправки и мессенджеры настраиваются в `company`.
- [src/app/theme.css](src/app/theme.css) — основные цвета и отступы.
- [public/images](public/images) — локальные изображения в WebP. Авторы, исходники и происхождение эскиза и концепции указаны в [PHOTO-CREDITS.md](PHOTO-CREDITS.md).
- `transformation.photoSet` заполняется для одного объекта. Укажите его название (`project`) и три изображения (`photos`) в порядке «эскиз, концепция, результат». Для каждого нужны локальный путь `image` и описание `alt`. Подготовьте кадры с одинаковой геометрией, ракурсом и соотношением сторон 16:10. Широкие экраны используют переход по прокрутке, кнопки стадий доступны на любом экране. При `photoSet: null` кнопки показывают статус каждой стадии.
- Перед публикацией укажите фактический адрес сайта в `NEXT_PUBLIC_SITE_URL`, чтобы ссылки Open Graph указывали на нужный хост.

## Подключение заявок

Демоформа проверяет поля в браузере. Результат проверки честно сообщает, что заявка не отправлена. Для рабочего сайта подключите [адаптер формы](src/lib/inquiries.ts) к серверному обработчику, который проверяет данные и доставляет заявку в согласованный канал. Замените демонстрационные контакты и согласуйте политику обработки персональных данных и текст согласия перед запуском.

## Анимации

Единые значения движения лежат в [src/lib/motion.ts](src/lib/motion.ts) (длительности, паузы между элементами, easing) и в [src/app/theme.css](src/app/theme.css) (переменные для CSS-переходов). Сценарии появления секций описаны в [src/components/section-motion.tsx](src/components/section-motion.tsx), а анимация первого экрана в [src/components/sections/hero.tsx](src/components/sections/hero.tsx).

- Простые эффекты наведения (кнопки, стрелки, подчёркивание ссылок, фото проектов) сделаны на CSS и работают только на устройствах с мышью.
- Появление секций, линий и этапов ремонта сделано на GSAP ScrollTrigger. Прокрутка страницы не перехватывается и не замедляется.
- При включённой настройке системы «уменьшить движение» анимации не запускаются, страница показывается сразу в готовом виде.
- Стартовое состояние первого экрана задаёт маленький скрипт в `layout.tsx` (класс `intro` на `html`). Он снимается при запуске анимации или через 3,5 секунды.
